# 项目 C · 客户分层客单价差异的统计检验

> 数据：项目 A 的零售交易库（4,338 名客户）｜生成 2026-11-19

## 问题

核心客户（R 高、F 高、M 高）的**客单价**是否真的高于其他客户？还是随机波动？

## 方法

| 步骤 | 做法 |
|---|---|
| 分组 | 按 R/F/M 各自中位数切分，取「R 高 F 高 M 高」为核心组，其余为对照组 |
| 检验 | 两独立样本**置换检验** 5,000 次：打乱分组标签，看观测均值差在随机分布里的位置 |
| 区间 | **Bootstrap** 2,000 次重采样，给出均值差的 95% 置信区间 |
| 效应量 | **Cohen's d**：差异相对于波动的量级 |

## 结果

- 样本量：核心组 **1,426** 人，对照组 **2,912** 人
- 客单价均值差（核心 - 对照）：**145.26**
- 置换检验 **p = 0.0024**（5,000 次）
- Bootstrap 95% 置信区间：**[33.35, 287.99]**
- Cohen's d = **0.08**

## 结论

差异**统计显著**：核心客户客单价均值高 145.26，95% 置信区间不含 0，效应量 d=0.08（小）。业务上可以认为分层有效，但幅度有限，行动上应优先做「频率」而非「单价」。

## 面试怎么讲（1 分钟）

> 我用置换检验验证了一个业务假设：核心客户和非核心客户的客单价有没有真实差异。置换检验不依赖正态假设，适合这种右偏的金额数据；我同时给了 bootstrap 置信区间和 Cohen's d，避免只看 p 值。结论是……（按上面结果说），所以运营策略应该打频次而不是单价。

## 局限

- 观察性数据，不是随机实验，只能说相关不能说因果；
- 客单价右偏严重，均值敏感，报告里同时看中位数更稳；
- 若要做真实验，需要对召回策略做 A/B 测试。
