# 电商用户行为分析报告（已填数 · 核对后可直接用）

> 数据：Online Retail 真实交易记录（541,909 条原始）｜分析周期：2010-12 至 2011-12｜作者：戴雍燊
> 数字来源：本目录 `reports/result.md`（2026-11-19 实跑）。核对无误后可原样用；想改结论就改，别改数字。

## 1. 背景与问题

电商业务想知道：**现有客户里，谁值得投入、谁快流失了**。本分析用 **39.8 万条**有效交易记录（覆盖 **4,338 名客户**、**18,532 张订单**、总销售额 **£8,911,408**）回答三个问题：客户复购情况如何？销售额集中在哪类客户？该对哪类客户做什么动作？

## 2. 数据与处理

- 原始 541,909 条 → 清洗后 397,884 条：剔除取消单（InvoiceNo 以 C 开头）、退货（数量或单价 ≤0）、缺失客户 ID 的记录。
- 指标定义：
  - 复购率＝下单 ≥2 次的客户占比；
  - 留存＝首购后 30/60/90 天内有再次购买的客户数；
  - RFM＝R 最近一次购买间隔、F 订单频次、M 消费金额，按各自中位数切分三档。

## 3. 主要结论

1. **复购**：复购率 **65.6%**，人均 **4.27** 单——老客是主要盘。
2. **销售额高度集中**：核心客户（R 高、F 高、M 高）**1,426 人，占 32.9%**，却贡献 **76.3%** 销售额。
3. **季节性明显**：月度 GMV 从 2011-02 低点 £447k 一路攀升至 2011-11 峰值 **£1,161,817**（圣诞备货季），说明旺季前是运营投放的关键窗口。
4. **高价值流失预警**：**597 名**曾高频高额客户已长期未购买（R 低、F 高、M 高），占销售额 **12.9%**——这是最值得做定向召回的群体。
5. **留存分布**：首购后 30 天内回购 812 人、31–60 天 998 人、61–90 天 921 人，90 天后仍回来 2,188 人——回购窗口分散，单点召回不够。

## 4. 三条建议

| 客户类型 | 建议动作 | 预期效果 |
|---|---|---|
| 核心客户（1,426 人 / 76.3% 销售额） | 会员分层 + 旺季前专属上新与预留库存 | 稳住基本盘，降低旺季缺货流失 |
| 高价值流失（597 人 / 12.9% 销售额） | 定向召回：专属券 + 老客回访 | 召回 10%–20% 可挽回约 1.3%–2.6% 销售额 |
| 低频低额（1,013 人 / 2.9% 销售额） | 自动化营销，降低人工触达成本 | 释放人力到前两类客户 |

## 5. 局限与下一步

- 局限：数据来自单一国家（英国）零售商，缺成本与渠道信息，结论偏行为层；RFM 只反映结果，不解释原因。
- 下一步：引入用户行为序列做流失预测；对召回券做 A/B 实验验证真实提升；把 RFM 从快照升级为月度滚动。
