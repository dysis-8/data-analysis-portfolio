# 数据分析作品集｜电商用户行为分析 + 统计检验

中山大学统计学本科生（2027 届）的个人数据分析练习项目。两个项目都用真实公开数据，从清洗、取数、分析到结论输出走完整流程。

---

## 项目一：电商用户行为分析（RFM 与用户分层）

**数据**：UCI Machine Learning Repository — Online Retail Data Set（英国在线零售交易明细，541,909 行）

**做了什么**

1. **数据清洗**（`项目A_电商RFM/prepare.py`）
   - 剔除取消单（InvoiceNo 以 C 开头的负数订单）、退货（数量或单价 ≤ 0）、客户 ID 缺失的记录
   - 有效数据从 541,909 行降到 397,884 行，覆盖 4,338 名客户、18,532 个订单
2. **指标口径与分析**（`项目A_电商RFM/analysis.py`，SQLite + SQL）
   - 复购率、留存（首购后 30/60/90 天）、月度 GMV
   - RFM 分层：R/F/M 各按**中位数**切分（金额右偏，均值会被大客户拉高），三项交叉成 8 类
3. **结论**（`项目A_电商RFM/report_filled.md`）
   - 复购率 **65.58%**，人均 **4.27** 单
   - 核心客户 **1,426 人（32.9%）贡献 76.3% 销售额**
   - 高价值流失客户 **597 人（12.9% 销售额）**——召回优先对象
   - 月度 GMV 从 2011-02 的 £447,137 低点升到 2011-11 的 £1,161,817 峰值（旺季效应明显）

## 项目二：客户分层差异的统计检验

**问题**：核心客户与普通客户的客单价差异，是真实存在还是随机波动？

**方法**（`项目C_统计检验/run.py`）
- 置换检验（5,000 次重排）得到经验 p 值
- Bootstrap（2,000 次）估计均值差的 95% 置信区间
- 计算 Cohen's d 评估效应量

**结果**（`项目C_统计检验/result.md`）
- p = **0.0024**，95% CI **[33.35, 287.99]**，Cohen's d = **0.08**
- 结论：差异不太可能是随机波动，但**效应量很小**（d=0.08）——业务上「显著」不等于「值得做」，建议运营优先做复购频次而非提价
